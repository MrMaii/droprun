## What changed

The share editor shows the saved direct/plan-review preference or an unconfirmed
setting before Send. It explains the consequence and that the Relay's setting
on first receipt determines the task mode. The notice does not change settings,
bypass approval or prevent a locally queued share. Effort summaries use localized
meanings while request values remain exact. Chinese project permission copy
retains the execution-setting qualifier.

Offline and notification-off saved feedback has a four-second base reading
window, the existing accessibility extension and immediate Close. Flight completion
refreshes the explanation. Ordinary saves return promptly with neutral copy.
The Codex capsule grows with text; pending execution settings expose their
disabled state. Structural keyboard focus preserves page colors; background
settings refresh retains focused appearance/language choices. Invalid manual
pairing retains entries and shows the complete error without a request.

The bilingual README leads with the three-step screenshots, then a smaller tour.
Original light/dark EN/ZH SVG diagrams and accessible text explain the local and
Relay boundaries. Screens and tours remain **0.5.1 development UI, October5**,
with labelled Demo data; they predate later refinements and are not recordings of
this download or genuine Codex execution. [Media provenance](../../assets/brand/readme-media.md).
