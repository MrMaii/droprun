## What changed

Home keeps sync failures compact, retains the reader's place and shows complete
large project names. A delivery puts result, preview and files on one surface;
inspection is primary and follow-up remains separate. Execution-setting progress
and results sit beside the choices, survive page recreation without replay and
announce success once. Old project-permission feedback cannot close later dialogs.
Windows setup separates required readiness checks from optional media extraction.
README brings downloads and installation forward and shows the current delivery
region in a visibly labelled memory-only capture.
