Public candidate, October 6, 2026 UTC. Share keeps a persistent optional-note
label; older Home and Project History entries show a calendar date. The website
puts the share flow first, with real native development media. [Candidate12](0.5.12-rc.1.md)

## What changed

- **Your note · optional / 留言 · 可选** stays above the editor after typing.
  The shorter hint leaves room for Send and draft feedback. No material,
  permission, saved-note or execution behavior changed.
- Recent entries retain relative dates. Entries at least seven days old use an
  explicit English/Chinese calendar date in the system timezone; missing dates
  stay identified. Duration formatting and ordering are unchanged.
- Website and README use the accepted code26 Share stills and captioned native
  project → note → back → model clips. Code25 recordings predate the persistent
  label and remain marked memory-only: no task is sent. Earlier media is retained.
- Relay health matches runtime 0.5.13. Two Browser.close tests tolerate only the
  exact connection-ending error, with endpoint refusal, reused-port protection
  and recovery still verified; production browser code is unchanged.
