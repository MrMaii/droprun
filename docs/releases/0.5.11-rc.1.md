## What changed

- Home gives each used project a matte card, clear name/count and state/date row.
  Decorative initials hide at large text sizes.
- Settings groups model availability, Refresh/Retry and choices on one surface.
  Existing reads preserve cached models and current reading/focus. Refresh does
  not save or approve an execution-mode change.
- History distinguishes loading, read failure and confirmed empty results;
  cached rows remain readable. Busy Refresh is unavailable with an accurate
  description. Rows put state before full-width source/date.
- Share searches the displayed project label or full ID while retaining the
  selected destination, materials, order and permission rules.
- Task reports preserve reading in the checked same-content, in-process
  recreation case; refresh failures have useful localized feedback. Primary
  actions use a matte lime surface.
- Retention periods/recovery use stronger text in a Settings group. Its policy
  and data behavior stay unchanged. Native paragraph acceptance remains open.
- Both READMEs lead with installation, a shorter workflow and accepted native
  examples. The website gives Share recordings more room. Existing recordings
  keep their dated development/sample scope.
- Miniflare's sharp child uses the scoped 0.35.5 override; Cloudflare tools stay
  pinned. The actual Windows payload and fixed in-memory PNG check passed.
