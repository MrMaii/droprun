# Compact README cover · 2026-10-07

The anonymous English GitHub preview at source6d3b10e showed a real narrow-screen
problem: the1280×448 cover rendered at309.33×108.26 in a requested390px viewport.
Its value statement and platform labels became tiny. The original browser JPEG
was saved, reopened and retained as the baseline.

Four separate640×480 compact covers preserve the original mark, colors and
two-line value statement. The platform labels now occupy separate lines.
Both READMEs select these below600px, with dark/light variants; desktop artwork
and native media remain byte-exact. The installation link, prerequisites and
text description remain ordinary accessible text outside the artwork.

Generate compact artwork with `node scripts/build-readme-cover.mjs --compact`.
Root directly viewed all four new originals: their full mark, names, value
statement and labels fit. This is artwork review, not native execution or a
GitHub responsive-rendering result. Published narrow display is still pending.
The desktop source's separately accepted display remains in the
