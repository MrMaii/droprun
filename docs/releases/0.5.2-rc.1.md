## What changed

Native Java Views now share warm neutral surfaces, lime actions, dark appearance
and press/selection/focus/disclosure feedback. Home leads with project identity,
counts and state; sharing keeps project context; delivery leads with the result;
settings groups the real computer and configuration. Pair actions precede setup
help. Large-text task states and their dates stack and remain fully readable.

Plan review describes configuration, not a pending approval or isolated copy.
Unknown modes remain unknown. Discard confirmation names saved phone copies and
the note; source originals stay intact. Saving feedback describes phone
persistence rather than Relay receipt or Codex execution.

Windows setup distinguishes saved settings, last verified deployment and a
current connection response. Invalid account/name/cost fields focus errors without
sending a request. Pairing requires a live Relay response. Pairing pages show
source/instance, hide expired invitations and recover failed clipboard copying.
Existing confirmation/local-token/server pairing authority remains intact.

The bilingual website and README use sixteen actual native captures and short
unretimed tours. Their provenance remains **0.5.1 development UI, October 5**,
before the source bump. This candidate includes that pass and the later typography
correction. Demo labels remain; no genuine task or execution success is represented.
[Media provenance](../../assets/brand/readme-media.md).
