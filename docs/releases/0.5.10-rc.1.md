## What changed

- **Read the result first.** A clearer result heading and page-width text keep
  the task title, result and next actions distinct. Original result-list lines
  remain separate; the existing first-paragraph/200-character summary limit and
  full report are preserved.
- **Find the preview action.** Ready-preview explanation sits close to its
  action, with its selectable text and existing permission checks intact.
  Preview eligibility, expiry and request handling are unchanged.
- **Trust action feedback.** An exception is a failure even when its message is
  null, empty or whitespace. Nonblank original details are kept. Otherwise the
  dialog asks the user to check the handoff's latest status before trying again.
  The existing callback restores controls and refreshes the foreground task.

[Task results and action feedback](ui-task-results-feedback-2026-10-06.md) owns
the focused native evidence and original screenshot boundaries. This candidate
includes the action-feedback fix identified after the 0.5.9 build.
