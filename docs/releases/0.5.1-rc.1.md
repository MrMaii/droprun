## What this candidate delivers

The Android UI has compact project history, grouped settings, result excerpts,
visible full-report disclosure, press/focus feedback and native transitions.
Share recovery preserves materials, intent and identity. Confirmed deletion
evicts paged caches and blocks stale outbox replay; uncertain deletion retains
the report. Only explicit DELETE 404 offers separately confirmed phone-cache
clearing, without claiming cloud deletion.

Windows update/uninstall refuse busy, unknown or unsupported legacy workers,
seal new work after accepted stop and wait for the verified PID to exit.
Intentional shutdown no longer restarts the supervisor. Running legacy workers
must finish their work and be stopped manually before replacement.

Cloudflare dependencies receive compatible security fixes. Service health
versions now match 0.5.1. CI builds with the canonical website origin and checks
that generated pages retain their committed contents before Windows packaging.

## Remaining stable-launch gates

- Three genuine projects, five consecutive complete handoffs and twenty real
  sources, recording actual text/audio/frame coverage and failures.
- Physical Android accessibility, background reliability and performance;
  clean Windows + fresh owner Cloudflare + phone installation, pairing,
  first delivery, upgrade and uninstall.
- Genuine offline/revocation/approval/preview-expiry/upgrade-failure recovery,
  provider URI loss, storage-full and maximum-size behavior.
- The earlier SyncJob ANR remains unexplained. The approved 240-row history
  process-loss probe was rejected with `blocked by policy`; it was not executed
  or bypassed. Passing different fixture checks does not close that gap.
- Genuine end-to-end demo and final poster variants after UX acceptance.
  Unreviewed promo-film changes and social posting are excluded.

You operate your own Cloudflare and local Codex; provider usage can cost money.
This release establishes public candidate delivery, not completed stable
acceptance or marketing handover.
