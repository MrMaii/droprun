## Changes from rc.1

Bundled Windows scripts now receive a process-only execution policy. This covers
portable launch, installer launch/update/uninstall, the scheduled Connector,
service setup and media extraction. Nine source entry sites and eight runtime
payload sites were checked. Persistent user/machine policies are not changed;
organization Group Policy still takes precedence.

Live preview shutdown confirms owned process closure before project work proceeds.
Termination errors, nonzero results and an unknown result after five seconds block
the operation and retain handles for retry. Closing entries cannot be returned as
ready or renewed. Concurrent shutdown shares a barrier and emits one successful
notification. Already exited or signalled processes are not terminated again.
Quick Tunnel startup registers its child before awaiting readiness.

Android source and UI are unchanged from rc.1. The signed APK and source bundle
were rebuilt against this candidate's exact commit. Native screenshots and the
earlier labelled UI-tour remain demonstration material, not genuine Codex work.
[rc.1](0.5.1-rc.1.md) retains the preceding Android/UX changes and dated evidence.

## Validation and limitations

[Released-source CI](https://github.com/MrMaii/droprun/actions/runs/37264031106)
passed both jobs: Node tests, dependency audit, canonical website generation,
public-source scan, Windows packaging, Android debug/test builds, JVM tests and lint.
Local full Node: **218/218, no skips,33.576s**. Four added synthetic lifecycle
tests cover delayed closure, termination failure, timeout, retry/concurrency and
natural/signal exit. Existing native local live-preview tests now assert the owned
PID is gone and the old port is unavailable before returning from shutdown.

The first source CI reported `EBUSY` during temporary preview-fixture cleanup.
Eight local probes confirmed exit/close and immediate cleanup; three additionally
checked that the PID was gone and the old port was unavailable. Evidence for those
probes is retained in this session's tool output; the original lock holder remains
unknown. Temporary-directory cleanup now has finite retries. The independent
production closure barrier addresses the
documented stop-before-edit contract, not a proven diagnosis of that CI lock.

A first final local suite saw an unrelated Miniflare brand-fixture `ECONNRESET`.
The isolated case and complete recheck passed. No mutation retry was added to
production, and the cause is not claimed resolved. Original logs are retained.

Android local evidence remains the dated rc.1 snapshot: JVM23/23, lint0errors/
28warnings, native89/89 per API26/API35 at200% font. These were not rerun here;
Android source is unchanged. [UX evidence](0.5.1-ux.md) and
[UI coverage](0.5.1-ui-matrix.md) preserve their dates and limitations.
