# Home: read the part that distinguishes a project

Development after public source `3139f589`, 2026-10-07; outside signed
candidate14. Home previously capped an independent project name at two lines
at normal text size. A long shared prefix could hide whether the destination
was the mobile or desktop project. Names now wrap completely on every bind.
Only two production `maxLines` expressions change; card widths, typography,
identity, status, feedback and navigation retain their existing behavior.

## Retained failures

The original two-line baseline fails `Fit all lines vertically` in 5.771s at
the new complete-name assertion. After the two production changes, a separate
take fails the first/final-line visibility predicate in 14.136s. Each fails one
JUnit, closes only the first English/light/font1 window, records a zero
after-destroyed guard and font/language restoration, and stops before the other
five windows or native after-device reads. Each retains 42 returned children
and 84 original outputs with its own independent failure review. Neither is
relabeled successful.

The second failure exposed a test coordinate issue: Android's
[`View.requestRectangleOnScreen` implementation](https://raw.githubusercontent.com/aosp-mirror/platform_frameworks_base/android-15.0.0_r1/core/java/android/view/View.java)
mutates the caller's `Rect` while traversing parent coordinates
(`android-15.0.0_r1`, lines 7951–7978, checked 2026-10-07). The test now passes a
copy, keeps the original local rectangle for the same visibility predicate,
and adds requested/shown/row/tail to failure messages. Actual failed geometry
was not logged. Production wrapping and the predicate remain unchanged.

A separate initial file-only reader failed because universal newline decoding
changed the AVD stdout's CRLF. A fresh followthrough used raw byte decoding;
the original reader failure remains. This correction did not rerun native UI.
