# 商业验证计划

状态：提议，未验证。来源为原会话第 1 轮助手回复，不是用户已批准价格或市场研究结论。

## 价值与用户

把外部参考更可靠地变成已有项目的实际工作。只遥控 agent 或总结视频不足以表达差异。

首批用户假设：已经用 coding agent 做真实项目，会从 UI、交互、实现教程中寻找灵感的人。

## 两周对照实验

招募 10 人，使用真实内容，对比直接交给现有 agent 与通过 DropRun：

- 获得可用交付前的复制、切设备、解释和补充材料次数。
- 素材可读率；URL 接收与视频取得分别计数。
- 正确投递率、耗时、采纳或合并率。
- 第二周主动复用与真实付费行为。

早期继续投入门槛：至少 5 人第二周复用、至少 3 人愿按测试价格付费。不是行业标准，也不能证明大众市场成立。

## 价格与成本

历史提议：USD 12/月，30 次、不超过 5 分钟的视频处理与项目交办。原型技术上限不是已售套餐。

原会话预算：12.00 收入，减假设商店费 1.80、处理成本 3.00、其他可变成本 0.50，剩余贡献 6.70 美元。未计获客、客服、开发、固定费用与税费。

数字仅保留为历史算例。Apple 佣金、模型价格、商店规则本轮未复核；Android 原型不得套用 Apple 费率作当前利润承诺。实际核算须记录账单、重试、存储和 agent 消耗。

收费前明确：DropRun 服务费包含什么；视频处理用谁的额度；Codex 执行是否消耗用户现有账号额度。不得承诺无限视频或无限执行。

## 发布门槛

材料授权、隐私披露、保留/删除、设备撤销、费用说明，以及发行地区、商店、供应商条款、商标核查必须完成。demo、下载量、口头称赞均不能替代商业验证。
