# ADR 0005：按手机、按项目授权隔离执行

状态：Superseded（固定隔离执行范围；设备/项目授权版本与撤销规则保留）；日期：2026-09-07。

新原目录权限边界见 [ADR 0009](./0009-original-project-plan-approval.md)。旧隔离许可不能静默扩大；原目录写入需要批准具体计划，或主动确认开启该手机的直接执行设置。下文保留旧范围和验证依据。

## 决定

全部 Codex 本地项目保持可见，未授权项目显示“未授权”，不从列表隐藏。首次交办必须确认固定的隔离执行范围，之后可从“项目授权”停用或再次允许。配对手机只管理自己的授权，不影响其他手机。

当前范围允许读取项目源码、创建隔离副本、在副本修改与运行本地命令/测试；不自动合并原项目。沿用当前网络允许、读取未完全限定到项目、MCP/插件关闭的边界；界面明确披露，不把该开关称作细粒度 ACL。副本外命令仍须 [单次审批](./0004-single-command-approval.md)。后续不能无提示扩大已确认范围。

## 强制路径

- D1 保存 device_id/project_id 的 enabled 与授权版本。重复相同状态不更换版本；停用再允许产生新版本。
- 新任务和追问仅在当前授权有效时进入队列，任务保存服务端授权版本，忽略客户端伪造值。
- 停用与取消未完成任务使用同一 D1 batch；排队任务 cancelled，活动任务收到 cancel_requested。重新允许不复活它们。
- 领取任务、电脑复制源码前、创建/恢复会话前、开始回合前均校验授权；Connector 对准确任务/项目/版本/固定 profile 做检查，查询失败不开始执行。
- 活动任务沿用状态轮询发现取消，调用 turn/interrupt；既有命令审批也因任务取消而失效。停止不是回滚，不保证撤销已经发生的副作用。

## 限制与替代方案

不选择“未授权项目不显示”，因为用户明确要求全部项目。也不只在 Android 禁用按钮，否则旧客户端和直接 API 请求仍可能执行。

固定范围减少首次配置负担，但不是逐路径、逐测试命令或网络目的地配置。活动取消受轮询、网络和 App Server 响应影响；电脑断网不能立即收到撤销。授权未采用硬件身份或电脑端二次签名，配对令牌持有者被视为该手机的用户；配对码安全仍须单独补齐。

旧客户端不能隐式取得新授权；未带授权版本的历史排队任务不执行。历史终态报告保留，追问需要当前有效授权。当前没有把旧项目批量默认授权。

## 验证与依据

测试与真实手机记录见 验收账本（历史私人验收记录，未随公开版分发），字段/端点见 [CONTRACTS](../technical/CONTRACTS.md)。官方依据：[D1 batch](https://developers.cloudflare.com/d1/worker-api/d1-database/#batch)、[App Server turn/interrupt](https://learn.chatgpt.com/docs/app-server)，2026-09-07 核查，并对照本机 TurnInterruptParams。
