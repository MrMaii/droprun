# ADR 0010：0.1.7 采用便签 droprun 字标与轻量原生视觉

日期：2026-09-07（Toronto）  
状态：已采纳用于当前私人版本；不是商标或字体定稿

## 决定与来源

用户在指定便签上要求全小写 `droprun` 艺术字，随后明确要求“完整地把所有新资产动画以及优化好的版本上线”。本轮以最新 v5 为发布视觉锚点，保留原深绿/青柠配色，不把被否定的旧 Logo 一并发布。

沿用 Java 原生界面，以一个 `BrandUi` 共享样式入口统一两 Activity。渐层、叠层、高光和边框构成玻璃感；不增加 UI 框架或声称真实背景模糊。文字使用系统字体，生成式艺术字仅随原稿复用。资产唯一来源见 [品牌资产](../../assets/brand/README.md)。

主动导航采用 220ms 入场；按压 130ms；项目选择有反馈。尊重 Android 系统动画关闭，网页尊重 `prefers-reduced-motion`。后台轮询不得反复播放入场或无条件重建列表。

## 约束

固定品牌文件可以公开；配对码、用户任务、交付文件不因品牌发布而改变权限。通知与系统单色图标采用简化便签符号，正文状态必须含文字。保留现有私人签名以支持覆盖更新；商店签名、SVG 母版和可安装品牌字体另行决策。

本次上线授权指现有 Cloudflare + 本机 Connector + 私人 APK 下载渠道，不推断为应用商店上架或完整 MVP 验收通过。发布证据见 0.1.7（历史私人发布记录，未随公开版分发）。
