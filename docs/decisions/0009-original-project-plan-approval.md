# ADR 0009：原项目执行、默认计划审批与手机直接执行开关

状态：Accepted；实施与发布证据另记。
日期：2026-09-07（Toronto）

## 背景

用户实际分享已被 Connector 领取，但 一个项目的大量历史压测产物被纳入源码快照，超过 20000 文件限制，任务在创建 Codex 会话前受阻。用户随后明确改变产品方向：不再复制项目；直接进入已有项目的新会话，先把理解和计划回传手机，由用户决定是否执行；手机可主动开启直接执行。

这是新的产品决定，不是提高快照上限或删除用户文件的授权，也不把原来的隔离执行许可自动扩大为原目录写入许可。

## 决定

- 每次新分享在所选 Codex 项目的原工作目录创建独立会话，不复制源码、不创建任务 worktree。追问继续原会话，新追问同样使用原目录。
- 默认 `review`：只读项目与材料，生成理解、应用判断、实施计划和验证安排，回传手机后进入 `awaiting_plan_approval`。计划是待审批建议，不是完成交付。
- 用户明确批准当前计划版本后，任务进入 `queued_execution`；Connector 在同一会话开始执行回合，在原目录修改和验证。拒绝计划或取消任务不会执行，也不自动回滚已发生操作。
- 手机设置 `directExecution` 默认关闭，作用于此配对手机向所有已允许项目提交的新任务，包括追问。只有联网展示风险并明确确认后才能开启；直接执行仍需要项目授权。
- Relay 首次接受新任务时固定 `review` 或 `direct`。相同任务的幂等重传沿用原模式。开关改变不追溯改变已存在任务，不放行等待批准的计划，也不自动重跑终态任务。
- `direct` 允许新任务跳过计划批准，直接在原目录工作。风险确认须明确说明会修改现有文件、保留已有改动、取消不等于回滚；关闭仅影响之后的新任务。

## 权限与执行边界

- 计划回合使用只读 sandbox，网络关闭，不允许提升权限审批。后台 MCP、插件和 Apps 继续禁用；不能用这些能力绕过只读边界。缺少读取能力时明确受阻。
- 批准具体计划或主动确认开启 `directExecution` 是新的原目录执行授权。旧 `isolated-workspace` 项目授权只表示该手机可继续向项目交办，不能单独触发原目录写入。
- 已批准和 `direct` 执行回合使用原目录 `workspaceWrite`，允许普通本地命令、修改及验证。超出目录/权限范围的命令仍须单次审批；生产发布、生产数据、付费、对外发送、重要删除等高风险动作仍需对应的单独授权。
- 计划批准只绑定当前任务、会话和计划版本。旧版本、非所属手机、取消/撤销后的批准无效；不得授予整段会话的无限权限。
- 直接修改会与用户其他客户端共享工作树。保留用户已有修改，实际执行前重新检查相关文件；本决定不宣称完整冲突隔离、回滚或细粒度读取/网络控制。

字段、端点、状态与幂等规则统一见 [CONTRACTS](../technical/CONTRACTS.md)，不在多处维护字段定义。

## 交付与旧任务兼容

- 保留产物 SHA-256、真实命令/文件事件和完成前证据检查；不做全目录快照或全量改动扫描。删除以成功的 `fileChange` 删除事件及文件实际不存在核对。原目录交付准确说明直接修改的项目位置及实际文件，不再称作“副本交付”或“尚未合并”；这些检查不能完整区分其他客户端修改或所有 shell 写入。
- 不为原目录任务自动生成或要求 `changes.patch`；仍可下载显式声明并通过核验的产物。若用户任务需要差异文件，应作为显式产物生成和检查，不能把用户原有改动冒充本任务差异。
- 旧数据库记录保留 `legacy-isolated` 兼容标记，已有运行恢复继续原副本语义，旧终态及报告不重写。新提交和新追问不再继承副本，即使父任务是旧隔离任务。
- 旧运行恢复不能用最近其他回合替代准确的任务回合，不能为了迁移默认重跑。历史快照文件保留，不主动清理或复制回原项目。

## 取舍与替代方案

在原项目直接工作能保留现有依赖、Git 状态和大项目上下文，避免每次分享先复制全部可见文件；代价是原文件会实际变化。默认计划审批让用户先看到具体范围，直接执行开关满足愿意预授权的手机用户。

不采用提高 20000 文件上限、删除历史产物或全局排除 `artifacts` 作为新流程的前置条件。旧快照限制仅属于旧任务恢复路径。也不把所有已配对设备默认开启直接执行。

## 验收

- 大量历史产物的项目无需快照也能创建正确项目/原 cwd 的会话；计划阶段原项目文件不变。
- 手机能查看计划并批准准确版本；批准前无执行回合，批准后同 thread、新 turn 执行。拒绝、取消、重复决定、旧版本与撤销均有相应验证。
- 开关默认关闭，开启有联网风险确认；不同手机互不影响。设置变化不追溯影响已有任务和待批计划，新分享及追问按首次服务端提交固定模式。
- 原目录执行能修改目标文件并产生真实验证记录，显式产物可下载；报告不再声称隔离副本交付或自动合并。
- 旧任务、终态报告与配对保留，旧运行恢复不重复执行。
