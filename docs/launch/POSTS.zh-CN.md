## V2EX / 中文发布文章

标题：做了一个开源工具：把手机参考交给本地 Codex 项目

我经常在手机上看到值得用的网页、交互或教程，但收藏之后，很少再把它带回正在做的项目。
DropRun 想缩短这次交接：在 Android 系统分享菜单里选择它，选一个已有项目，可以留一句话，
电脑上的 Codex 接着工作，手机呈现进展和可检查的交付。

这一版是 Apache-2.0 开源、自部署的公开预览版，支持 Android + Windows。
你的 Windows 电脑运行 Codex，你自己的 Cloudflare 账号运行中转和存储。
没有官方账号或订阅，供应商用量仍可能产生费用。电脑离线时只能排队，不能在云端执行。

首页按交办过的项目归类，独立任务和交办次数分开。可以直接执行，也可以先看计划。
材料读取有明确边界：收到链接不等于读完视频；报告说明取得的文本、音频与画面。
支持的静态网页可以提供版本快照，实时后端预览需要自己的域名和 Tunnel。

请先用小项目体验。发布记录说明已完成的测试和仍缺少的真机、真实来源验收。
演示视频是实际客户端界面，使用明确标注的演示数据，不冒充真实完整任务。
最需要的反馈是安装到首次交办过程中在哪里受阻，以及系统版本、失败阶段和来源类型。
请勿在公开 issue 中附配对码、令牌或私人材料。

源码、安装包与自部署说明：https://github.com/MrMaii/droprun

## Product Hunt 中文介绍 / Show HN 中文备稿

一句话：给手机上的好想法，一个进入真实项目的入口。

DropRun 通过 Android 系统分享接收材料，由 Windows Connector 交给本地 Codex，
再把进度、材料读取范围和验证证据带回手机。源码 Apache-2.0，自部署 Cloudflare。
首发是公开预览版，欢迎提供安装和首次交办反馈，不承诺任意视频可读或电脑离线执行。
