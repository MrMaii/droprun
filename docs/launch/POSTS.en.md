## GitHub Release

DropRun 0.5.0-rc.1 is the first public self-hosted preview for Android and Windows.
Share a reference from your phone into an existing local Codex project, then
inspect the task's actual reading coverage, changes and evidence.

You run the Cloudflare Relay and keep Codex on your computer. There is no DropRun
account or official subscription. Provider usage can cost money. Read the release
validation and setup guide before using it on an important project.

Downloads: signed Android APK, unsigned Windows per-user installer, portable ZIP,
checksums and a bilingual launch kit. Real-device and source-access gates remain
open; the included video uses labelled demonstration data.

## Show HN

Title: Show HN: DropRun – share phone references into local Codex projects

I built DropRun to shorten the gap between saving a useful reference on my phone
and doing something with it in an existing project. Android receives the share;
a Windows Connector hands it to local Codex; the phone shows progress and evidence.

It is Apache-2.0 and self-hosted on your own Cloudflare account. The first public
preview supports Android and Windows. The computer must be online to execute,
source access varies, and cloud/Codex usage is your responsibility. I would like
feedback on installation and the first handoff, especially failures with versions
and source types. Please keep private material out of public issues.

Source and downloads: https://github.com/MrMaii/droprun
