## Native UI tours

The English recording uses the light theme; Chinese uses the dark theme.
Both show actual project selection, note editing, model options, Settings and
the labelled demonstration report. The Chinese recording also shows closing
the share sheet and choosing “Keep editing” in the confirmation. Neither
recording sends a task or shows real Codex execution.

The original MP4s are copied byte-for-byte. GIFs use FFmpeg palette conversion
at 480 × 960 with a 12 fps sampling filter, Lanczos scaling and Bayer dithering.
No cuts, reordered actions, UI reconstruction or intentional speed changes.
Frame sampling and GIF centisecond timing yield 9.08 and 12.16 seconds; the
original videos are 9.084089 and 12.192133 seconds. Captions describe only the
visible UI actions and explicitly identify demonstration data.
