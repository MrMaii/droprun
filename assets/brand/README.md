# DropRun brand

`mark.png` is the selected original raster asset, reused without recoloring or
regeneration in Android and the website. SHA-256:
`5b53d5fba0abb6693006409f347e95e1dc1c82b557b027eb6b556c2adf7e72a1`.

Notification/monochrome icons are platform adaptations, not a vector master of
the wordmark. Body and UI text use platform system fonts; no Apple font or unknown
font is bundled. Current design decision: [ADR 0016](../../docs/decisions/0016-project-first-light-ux.md).

The logo is intentionally absent from the mobile home header. It remains useful
for the app icon, website, README and public release materials.

`readme-architecture*.svg` are original diagrams in English/Chinese and light/dark
palettes. They show the self-hosted flow and computer boundary, not a task result.
They use system fonts, contain no scripts or remote assets, and have text
equivalents in both READMEs. The selected logo and native captures are unchanged.

The dated native UI tour appears before the workflow gallery in both READMEs.
Its `picture` uses existing light/dark stills for reduced motion; explicit still
links remain available. Older tours are video links in a collapsed section.
Media bytes and the Demo/capture provenance remain unchanged. GitHub rendering
is verified separately from the source markup.
